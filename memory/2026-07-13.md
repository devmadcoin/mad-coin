### Game Page Carousel Fix
- Fixed right arrow button not working on mobile across all 3 carousels (Game, Digital Wearables, Video)
- Root cause: touch swipe handlers (`onTouchEnd`) fired with stale `touchEnd` state (initialized at 0), causing false swipe detection that interfered with button clicks
- Fix: Reset `touchEnd` to 0 on `touchStart`, added `if (touchEnd === 0) return` to skip swipe on simple taps, added `type="button"` and `pointer-events-none` on SVGs
- Committed and pushed, build verified clean

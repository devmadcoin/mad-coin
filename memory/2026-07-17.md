# 2026-07-17 — Full $MAD Website Rebuild

## Complete Website Remake: Next.js → Vite + React Router v7

User asked to "remake the whole website." Built entirely new stack in `mad-website-v2/`, then moved into `app/` replacing the old Next.js app.

### Old Stack (replaced)
- Next.js 14 with app router
- File-based routing
- API routes for Solana RPC

### New Stack
- **Vite 6** — dev server + build
- **React 19** + **React Router v7** (BrowserRouter, Routes/Route)
- **Tailwind CSS 3** with custom color tokens (`mad`, `ink`, `panel`, `bone`, `ash`)
- **shadcn/ui** — Dialog, Tabs, Collapsible components
- **Framer Motion** — scroll reveals, page transitions, lightbox
- **Google Fonts** — Anton (display), Space Grotesk (body), JetBrains Mono (monospace)

### Pages Built (8 total)
1. **Home** — Hero, Exchange Marquee, Movement, Latest Drop, Testimonials, Chronicles, Command Center, Team, Statement Marquee, Join CTA, Footer
2. **MAD Mind** — Philosophy cards, Numerology calculator, Frequency Quiz (8 questions, 5 archetypes), Knowledge Base
3. **Community** — Impact stats, communities supported grid with filters (all/recent/biggest), dev lock proof, Streamflow verification links
4. **Roadmap** — Phase timeline with milestones
5. **Game** — Mad Phonk Awakening stats, Roblox integration
6. **MAD Art** — Gallery grid with lightbox, video loops, featured banner
7. **Rewards** — Milestone table, holder verification via direct Solana RPC (no backend proxy), wallet checker
8. **Merch** — Product cards with live DEX price ticker, featured product, video embeds, proof photos

### Design System
- Animated SVG grain overlay (`grain`)
- Ember particle canvas (`EmberCanvas`)
- 3D tilt cards (`TiltCard` with mouse-tracking)
- Custom easing: `[0.22, 1, 0.36, 1]` (signature)
- Scroll reveal animations (`Reveal`)
- `PageShell` layout wrapper with eyebrow/title/sub pattern
- Glow shadows (`shadow-glow`)
- Dark mode only: `#050505` base, layered surfaces

### Key Technical Decisions
- Direct Solana RPC calls from browser (`api.mainnet-beta.solana.com`) instead of Next.js API proxy
- SPA routing with `vercel.json` rewrite rules for deep links
- All 327 public assets copied from old `public/` to new `public/`
- Product images reference existing `/stickers/` assets (Mad-Sticker-logo.png, etc.)
